# Quotely Android downloads

**Download the current APK:** [Quotely Android preview 6](https://github.com/jeesry22-afk/Invoice-App-Downloads/raw/refs/heads/main/Quotely-Android-v1.0.0-preview.6.apk)

This school project preview includes a separate Invoices Remaining dashboard card, readable full-width totals with icons on the right, document filters and status counts in one scrolling row with one selection at a time, Maya/GoTyme PH/GCash choices on the simulated payment page, and a reject action on quotation links. The payment page records a simulated amount against an invoice; no money is transferred. Email still opens your mail app until a dedicated sender address is configured.

On Android, open the APK after downloading it and allow installation from your browser or file manager if prompted. You can install this version over the previous preview without uninstalling. Keep a copy of important records because in-app backup and restore are not yet available.

This preview is signed with an Android development key, not a production Play Store release.

SHA-256: `770C34E634755725D839F740199E841A7EF70B5A403F1BD60A4EA44741957E9F`
