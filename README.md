# Quotely Android downloads

**Download the current APK:** [Quotely Android preview 10](https://github.com/jeesry22-afk/Invoice-App-Downloads/raw/refs/heads/main/Quotely-Android-v1.0.0-preview.10.apk)

This school project preview includes taller At a glance cards and an Invoices Remaining count with its unit, readable full-width totals with At a glance icons on the left, document filters and status counts in one scrolling row with one selection at a time, Maya/GoTyme PH/GCash choices on the simulated payment page, and a reject action on quotation links. The payment page records a simulated amount against an invoice; no money is transferred. Invoices and quotations now send automatically from Quotely with a confirmation sheet and animated success feedback. The sender profile picture comes from the Quotely Google account and its appearance depends on the recipient email app.

On Android, open the APK after downloading it and allow installation from your browser or file manager if prompted. You can install this version over the previous preview without uninstalling. Keep a copy of important records because in-app backup and restore are not yet available.

This preview is signed with an Android development key, not a production Play Store release.
