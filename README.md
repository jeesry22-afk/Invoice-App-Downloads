# Quotely Android downloads

Download the current Quotely Android preview from the [Releases page](https://github.com/jeesry22-afk/Invoice-App-Downloads/releases).

This update includes Google sign-in, cloud-synced business records, quotations and invoices, PDF sharing, and invoice emails with a simulated payment page. The payment page records an amount against an invoice for this school project; it does not transfer money.

On Android, open the APK after downloading it and allow installation from your browser or file manager if prompted. If you installed the previous preview, install this version over it without uninstalling; the package and signing certificate are unchanged. Keep a copy of important records because in-app backup and restore are not yet available.
