# Quotely for Android

**Download the latest APK:** [Quotely Version 1.0.3](https://github.com/jeesry22-afk/Invoice-App-Downloads/raw/refs/heads/main/Quotely-Android-v1.0.3.apk)

Version 1.0.3 improves loading after returning to the app: pending refreshes show a skeleton instead of an old error, and startup shows the Quotely logo without a spinner. This version includes Google sign-in, cloud quotations and invoices, PDFs, email delivery, client review links, and simulated payment links. Clients can be archived and restored. Clients without documents can be deleted; unsent drafts can be deleted; issued documents can be hidden and restored. Long press or swipe left on a client or document to reveal available actions.

Install the APK over your existing Quotely app to keep its data. Android may ask you to allow installation from your browser or file manager. The current APK is signed with the Android development key and is not a Play Store release.

The payment flow is a school project simulation. No real money is transferred. Phone push alerts depend on separate server configuration; the Dashboard bell remains available for in-app updates.
